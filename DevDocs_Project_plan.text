# 🤖 DevDocs AI — AI-Powered Developer Knowledge API

## 🎯 Project Goal

**DevDocs AI** হবে একটি production-style **AI + RAG Backend API** যেখানে developerরা তাদের PDF, TXT এবং Markdown documentation upload করে সেই documents-এর উপর AI-powered প্রশ্ন করতে পারবে।

Project-এর মূল লক্ষ্য:

* FastAPI দিয়ে production-style backend তৈরি করা
* RAG architecture practically শেখা
* Vector search ব্যবহার করা
* PostgreSQL + pgvector ব্যবহার করা
* Local development-এ Ollama ব্যবহার করা
* Production-এ Gemini API ব্যবহার করা
* JWT authentication implement করা
* Document processing pipeline তৈরি করা
* AI response-এর সাথে source documents/chunks দেখানো
* Free tier-এ live deployment করা

# 💰 Free Deployment Strategy

Project-টা এমনভাবে design করা হবে যাতে free-tier environment-এ run করা যায়।

### Production architecture

```text
User
  ↓
Render
  ↓
FastAPI
  ↓

  ↓
Supabase Storage

  ↓
Gemini API
```

### Local architecture

```text
User
  ↓

  ↓
Ollama
  ↓

  ↓

  ↓
```

# 🧠 Core Concept

DevDocs AI মূলত একটি **RAG system**।

RAG = Retrieval-Augmented Generation

Flow:

```text
Document Upload
      ↓
Text Extraction
      ↓
Text Cleaning
      ↓
Chunking
      ↓
Embedding Generation
      ↓
pgvector
```

তারপর user প্রশ্ন করলে:

```text
User Question
      ↓
Question Embedding
      ↓
Vector Similarity Search
      ↓
Relevant Chunks
      ↓
LLM
      ↓
Answer + Sources
```

# 🧹 6. Document Processing Pipeline

Upload করার পরে document process হবে।

Pipeline:

```text
Upload
  ↓
Validate File
  ↓
Save to Supabase Storage
  ↓
Extract Text
  ↓
Clean Text
  ↓
Chunk Text
  ↓
Generate Embeddings
  ↓
Save Chunks + Embeddings
  ↓
COMPLETED
```

যদি error হয়:

```text
FAILED
```

# 🤖 10. LLM Provider Architecture

আমরা সরাসরি router-এর মধ্যে Ollama বা Gemini code লিখব না।

Provider abstraction থাকবে।

Example:

```text
LLMService
    │
    ├── OllamaProvider
    │
    └── GeminiProvider
```

এতে environment অনুযায়ী provider পরিবর্তন করা যাবে।

```text

   ↓

   ↓
```

```text
   ↓

   ↓
```

```json

  "answer": "FastAPI dependency injection allows...",
```
